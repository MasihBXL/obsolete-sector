## 🪟 تم‌های مجزای ویندوز اکس‌پی و ویندوز ۹۸ با فونت‌های اختصاصی:

1. **تم Windows XP (پیش‌فرض - Luna Light Mode)**:
   - **فونت‌های اختصاصی**: فونت پیکسلی کشیده `VT323` برای تایتل‌ها و نوار عنوان، همراه با `Share Tech Mono` برای متن‌ها و دکمه‌ها.
   - **طراحی**: گوشه‌های گرد بالای پنجره (`border-radius: 8px`)، نوار عنوان آبی رویال Luna، دکمه بستن قرمز مرجانی اکس‌پی، تسک‌بار آبی با دکمه سبز رنگ استارت (`start`).
   - **رنگ‌بندی**: پس‌زمینه گرادینت آسمان Bliss، رنگ بدنه کرم/خاکستری دیالوگ‌های اکس‌پی (`#ECE9D8`) و محتوای سفید.

2. **تم Windows 98 Classic (تم کلاسیک دهه ۹۰)**:
   - **فونت‌های اختصاصی**: فونت رستر ۸ بیتی آرکید و داس **`Press Start 2P`** برای تایتل‌ها، در کنار `Share Tech Mono`.
   - **طراحی**: لبه‌های کاملاً تیز و مربعی بدون گردی (`border-radius: 0`)، خطوط سه‌بعدی برجسته Outset و Inset (`#FFFFFF #808080 #808080 #FFFFFF`)، نوار عنوان سرمه‌ای کلاسیک و دکمه‌های مربعی خاکستری `[_] [□] [X]`.
   - **رنگ‌بندی**: پس‌زمینه نمادین دسکتاپ فیروزه‌ای ویندوز ۹۸ (`#008080`) و تسک‌بار خاکستری با دکمه خاکستری استارت.

3. **تم The Backrooms Wiki (پالت رنگی پایگاه ویکیدات بَک‌رومز)**:
   - **پالت رنگی دقیق استخراج‌شده از `backrooms-wiki.wikidot.com`**:
     - زرد-کرم خیس کاغذ دیواری نمادین بَک‌رومز (`#EDE9DF`)
     - پس‌زمینه زیتونی-خاکی تیره فضای لیمینال (`#3C382A` ➔ `#4D4336`)
     - نوار عنوان طلایی-قهوه‌ای کهنه و نم‌کشیده هدر ویکی (`#A19370` ➔ `#7A6D52`)
     - رنگ متن زغالی تیره مونوکروم (`#1F1C14`) و لینک‌های هشدار نارنجی/امبر (`#B8530B`)
     - دکمه قرمز هشدار سطح خطر انتیتی‌ها (`#E61744`)
   - **طراحی و چیدمان**: Layout منظم و شیک قبلی بدون تغییر حفظ شده و تنها پالت رنگی ویکی اعمال شده است.

4. **تم‌های اختیاری CRT تاریک**:
   - `DARK CRT` (زغالی و تاریک صنعتی)
   - `PHOSPHOR GREEN` (سبز فسفری مانیتورهای قدیمی)
   - `AMBER MONITOR` (کهربایی آنالوگ)
   - `BLOOD NOIR` (قرمز تیره و خونین)

## 🕹️ قابلیت‌های طراحی شده (Features)

1. **طراحی بصری دقیق و وفادار به mikeklubnika.com**:
   - ستون‌های سایدبار مِش آنالوگ در دو طرف (`bannerleft` / `bannerright`)
   - بدنه و داک مرکزی کلاسیک با مرزبندی صنعتی و تم‌های مانیتور CRT
   - نوار بج‌های نوستالژیک وب ۱.۰ (88x31 Badges)
   - افکت اسکن‌لاین تلویزیون لامپی (CRT Scanlines Overlay) با قابلیت خاموش/روشن
   - تعویض تم مانیتور:
     - پیش‌فرض (تاریک صنعتی و زغالی)
     - **ویندوز ۹۸ کلاسیک / لایت مد (`WIN98 LIGHT`)**: با پس‌زمینه نمادین دسکتاپ فیروزه‌ای (`#008080`)، پنجره‌های خاکستری اصیل، نوار عنوان سرمه‌ای و متن‌های مشکی پرکنتراست
     - سبز فسفری (Phosphor Green)
     - امبر مانیتور (Amber CRT)
     - قرمز خونین (Blood Noir)

2. **سیستم صدای آنالوگ سنتز شده (Web Audio API Engine)**:
   - صدای کلیک رله‌های مکانیکی هنگام هاور روی لینک‌ها و بازی‌ها
   - صدای دگوس و بوق مانیتور CRT هنگام سوئیچ بازی
   - صدای درایو دیسک فلاپی (Floppy Seek) هنگام شروع دانلود بازی
   - پهپاد صوتی محیطی وحشت (Ambient Drone) در فرکانس بم ۴۰ تا ۸۰ هرتز

3. **کاتالوگ بازی‌ها با مانیتور تعاملی (Split Screen Monitor)**:
   - نمایش آرت پیکسلی و انیمیشن هر بازی در تلویزیون CRT زنده
   - مشخصات کامل: عنوان، تگ‌ها، نسخه، حجم فایل، تاریخ انتشار و تعداد دانلودها
   - دکمه دانلود مستقیم (**DIRECT DOWNLOAD**) با شمارنده خودکار دانلود
   - دکمه اجرای بازی تحت وب (**PLAY IN BROWSER**) در صورت داشتن خروجی HTML5 / WebGL
   - پنجره جزئیات جامع با گالری اسکرین‌شات‌ها، سیستم‌های بازی و لینک‌های Steam و Itch.io

4. **پنل مدیریت و آپلود بازی‌ها (Admin Upload Dashboard)**:
   - قابل دسترسی از آدرس: `http://localhost:3000/admin.html` یا دکمه `+ UPLOAD GAME`
   - رمز ورود پیش‌فرض: `1986`
   - امکان آپلود مستقیم فایل فشرده بازی (ZIP, RAR, 7Z, EXE) تا حجم ۵۰۰ مگابایت با نوار پیشرفت (Progress Bar)
   - آپلود کاور پیکسلی و تا ۶ اسکرین‌شات
   - بخش انتشار پچ‌نوت و گزارش‌های توسعه (Devlog Dispatches)
   - امکان مدیریت، مشاهده آمار دانلودها و حذف بازی‌ها

5. **ترمینال مخفی هکر (Secret Console Terminal)**:
   - فشردن کلید `~` (Tilde) در هر جای صفحه یا کلیک روی دکمه `terminal [~]`
   - دستورات تعاملی: `help`, `list`, `theme <name>`, `sound on|off`, `crt on|off`, `upload`, `clear`

## 🚀 نحوه اجرا (How to Run)

برای اجرای سایت در کامپیوتر خود:

```bash
npm start
```
یا
```bash
node server.js
```

سپس در مرورگر خود باز کنید:
- 🌐 پورتال اصلی: **http://localhost:3000**
- ⚙️ پنل آپلود و مدیریت: **http://localhost:3000/admin.html** (رمز ورود: `1986`)

```
│   ├── games/             # محل ذخیره بازی‌های آپلود شده
│   └── images/            # محل ذخیره کاورها و اسکرین‌شات‌ها

    ├── index.html         # صفحه اصلی کاتالوگ و مانیتور CRT
    ├── admin.html         # پنل آپلود بازی و مدیریت آرشیو
    ├── css/
    │   ├── style.css      # استایل‌های دارک، رترو، پیکسلی و CRT
    │   └── admin.css      # استایل پنل آپلود
    ├── js/
    │   ├── audio.js       # موتور صوتی تحت وب
    │   ├── app.js         # منطق فرانت‌اند و کاتالوگ
    │   └── admin.js       # منطق احراز هویت و آپلود فایل
    └── assets/            # وکتورها، کاورهای پیکسلی و بج‌ها
```
